## Выберите тип комнаты

| Комната | Когда пригодится |
| --- | --- |
| Временная | Создаётся без аккаунта и названия. Закрывается примерно через 15 минут после выхода последнего участника. |
| Постоянная | Для создания нужен аккаунт. Комната остаётся в списке, даже когда в ней никого нет. |

В оба типа комнат можно войти гостем по приглашению. [Первый звонок](/start/first-call)

## Создайте постоянную комнату

1. Войдите в аккаунт и нажмите **Создать комнату** в лобби.
2. Выберите **Постоянная**, введите название и нажмите **Создать комнату**.
3. Отправьте участникам ссылку из меню **Пригласить** или код из меню комнаты.

На следующую встречу можно зайти по той же ссылке. История чата сохранится.

## Переписывайтесь в комнате

1. Откройте **Чат** в комнате, напишите сообщение и отправьте его.
2. Через меню сообщения можно ответить на него или добавить реакцию. Чтобы исправить своё сообщение, выберите **Изменить**.
3. Для упоминания введите `@` и выберите участника. Если сообщение не ушло, нажмите **Повторить** рядом с ним.

Гости тоже могут писать в чат комнаты. Личную переписку можно открыть из [списка друзей](/rooms/friends-and-notifications).

## Управляйте постоянной комнатой

Чтобы изменить название и оформление, владелец открывает **Настройки комнаты**. В меню участника кнопка **Исключить из комнаты** завершает его подключение, а **Заблокировать в комнате** ограничивает повторный вход. Список заблокированных находится в разделе **Блокировки**.

Владелец может удалить чужое сообщение через меню. Чтобы передать сообщение на проверку администраторам VoiceRoom, [отправьте жалобу](/account/security#жалоба-на-сообщение).
