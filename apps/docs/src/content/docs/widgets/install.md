## Перед установкой

- Опубликуйте страницу по HTTPS. Если ваша страница сама открывается во фрейме, HTTPS нужен и родительским страницам.
- Убедитесь, что редактор сайта сохраняет и выполняет внешний `<script type="module">` в HTML-блоке. Некоторые конструкторы удаляют скрипты или запускают их в изолированном фрейме с ограничениями на микрофон и камеру.
- Если на сайте настроен CSP, добавьте `https://voiceroom.ru` к разрешённым источникам для `script-src` и `frame-src`. Если используется отдельная директива `script-src-elem`, разрешите этот адрес и в ней.
- Если сайт ограничивает устройства заголовком `Permissions-Policy`, разрешите микрофон для `https://voiceroom.ru`. Для видео разрешите и камеру. Даже при этих настройках браузер попросит гостя подтвердить доступ к устройству.

## Настройте и вставьте виджет

1. Откройте [конфигуратор](https://voiceroom.ru/widgets). Выберите размещение и оформление. Для голосовых комнат выключите **Камеру** в настройках виджета.
2. Скопируйте весь код из блока **Код вставки** и добавьте его в HTML страницы. Плавающую панель лучше вставить в основной HTML страницы, чтобы она могла располагаться в углу окна.
3. Опубликуйте страницу. При изменении настроек заново скопируйте код и замените им прежнюю вставку.

Пример кода для блока на странице:

```html wrap
<div data-voiceroom-widget data-config='{
  "version": 1,
  "mode": "inline",
  "background": "#171923",
  "text": "#ffffff",
  "accent": "#a5b4fc",
  "radius": 16,
  "corner": "bottom-right",
  "offset": 16
}'></div>
<script type="module" src="https://voiceroom.ru/widget/v1/loader.js" defer></script>
```

### Блок на странице

Ширину и высоту задаёт сайт. Например, чтобы блок занимал всю доступную ширину и имел высоту 480 пикселей, добавьте в CSS страницы:

```css
[data-voiceroom-widget] {
  width: 100%;
  height: 480px;
}
```

Значения в **Демо-контейнере** помогают проверить макет в конфигураторе. Если на странице высота не задана, виджет резервирует до 520 пикселей с учётом высоты окна.

### Плавающая панель

В разделе **Размещение** настройте ширину, высоту, угол и отступ. Эти значения сохранятся в коде вставки. На маленьком экране панель подстроится под доступное место.

## Проверьте звонок

1. Откройте опубликованную страницу и нажмите **Создать комнату**. Аккаунт VoiceRoom гостям не нужен.
2. Передайте код второму участнику. Он вводит его в виджете и нажимает **Войти**.
3. Проверьте звук в обе стороны, а для виджета с камерой — ещё и видео. По возможности используйте два устройства в разных сетях и проверьте, что панель удобна на телефоне.

Код действует только в виджетах VoiceRoom. Передавайте его участникам, которых хотите пригласить. Пустая комната со временем закрывается. Текстового чата в виджете нет.

## Если что-то не работает

| Что происходит | Что проверить |
| --- | --- |
| Виджет не виден | Проверьте HTTPS и убедитесь, что редактор опубликовал обе части кода. В консоли браузера проверьте, не заблокированы ли скрипт и фрейм. |
| Нет доступа к устройству | Проверьте разрешения браузера и системные разрешения, а затем выбранное устройство. Для камеры проверьте, включена ли она в настройках виджета. |
| Собеседника не слышно | Проверьте громкость и выбранное устройство вывода. Если браузер заблокировал воспроизведение, нажмите **Включить звук**. |
| Не получается войти | Проверьте код и убедитесь, что комната ещё открыта. Если комната открывается, а звонок не подключается, попробуйте другую сеть. |
