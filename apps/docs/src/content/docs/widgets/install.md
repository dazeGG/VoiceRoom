## Перед установкой

- Для страницы с виджетом и всех родительских фреймов нужен HTTPS.
- Проверьте, что редактор позволяет запускать внешний `<script type="module">` из HTML-блока. Некоторые конструкторы вырезают скрипты или запускают их во фрейме без доступа к микрофону и камере.
- Если на сайте настроена политика CSP, добавьте `https://voiceroom.ru` в `script-src` и `frame-src`. Если задана директива `script-src-elem`, добавьте адрес и в неё.
- Если сайт ограничивает доступ к устройствам через `Permissions-Policy`, разрешите микрофон для `https://voiceroom.ru`. Для видеозвонков разрешите и камеру. При запросе браузера гость подтверждает доступ сам.

## Настройте и вставьте виджет

1. В [конфигураторе](https://voiceroom.ru/widgets) выберите размещение и оформление. Если нужны только голосовые звонки, выключите переключатель **Камера**.
2. Скопируйте весь **Код вставки** в HTML страницы. Код плавающей панели добавьте в основной HTML, чтобы она располагалась в углу окна.
3. Опубликуйте страницу. При изменении настроек скопируйте свежий код и замените старый.

Так выглядит код для блока на странице.

```html wrap
<div data-voiceroom-widget data-config='{
  "version": 1,
  "mode": "inline",
  "background": "#171923",
  "text": "#ffffff",
  "accent": "#a5b4fc",
  "radius": 16,
  "corner": "bottom-right",
  "offset": 16
}'></div>
<script type="module" src="https://voiceroom.ru/widget/v1/loader.js" defer></script>
```

## Проверьте звонок

1. Откройте страницу с виджетом и нажмите **Создать комнату**. Гости могут войти без аккаунта.
2. Передайте код собеседнику. Он вводит его в виджете и нажимает **Войти**.
3. Проверьте, слышно ли вас обоих. Если включили камеру, проверьте и видео. По возможности повторите звонок с телефона в другой сети.

Код действует только в виджетах VoiceRoom. Передавайте его тем, кого приглашаете. Пустая комната со временем закрывается. Текстового чата в виджете нет.
