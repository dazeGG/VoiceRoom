# Font Assets

These WOFF2 files are self-hosted so the web app can keep `font-src 'self'`.

## Sources

- `onest-*.woff2`: Google Fonts CSS API, `https://fonts.googleapis.com/css2?family=Onest:wght@400..700&display=swap`, resolved to `https://fonts.gstatic.com/s/onest/v11/...` (variable weight, cyrillic-ext/cyrillic/latin-ext/latin subsets). Upstream license: `https://raw.githubusercontent.com/google/fonts/main/ofl/onest/OFL.txt`.
- `jetbrainsmono-*.woff2`: retained existing JetBrains Mono subsets. Upstream license: `https://raw.githubusercontent.com/JetBrains/JetBrainsMono/master/OFL.txt`.

Both families are licensed under the SIL Open Font License 1.1.
