## Design Context

### Users
VoiceRoom is for small groups who need quick voice rooms, persistent rooms, direct messages, and screen sharing with minimal setup. Users are likely switching between landing, lobby, and in-room controls, so repeated controls must feel predictable.

### Brand Personality
Dark, warm, voice-first, slightly tactile. The UI uses an olive/black surface system with electric-lime primary actions and warm off-white text.

### Aesthetic Direction
Refined dark product UI: compact but not cramped, rounded rectangular controls, clear command surfaces, and a consistent 4pt spatial rhythm. Avoid arbitrary one-off control heights and mixed button/input alignment.

### Design Principles
- Interactive controls use a shared sizing ladder: 36px small, 40px medium, 52px large, with 46px reserved for the in-room dock controls.
- Primary create/join actions share the large 52px rail so buttons, inputs, and submit segments align optically across landing and lobby.
- Use existing tokens and shared primitives before adding one-off CSS.
- Preserve the dark warm/lime visual language; standardize geometry without flattening brand personality.
