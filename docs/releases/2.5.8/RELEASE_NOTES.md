# VoiceRoom 2.5.8 — переход к чату из уведомления на десктопе

Хотфикс для 2.5.7.

## Исправлено

- Клик по системному уведомлению в VoiceRoomDesktop открывает чат: для личного сообщения — диалог, для сообщения комнаты — это сообщение в комнате. Раньше приложение только показывало окно.
- В приложении сообщения из одного чата больше не копятся в центре уведомлений: новое уведомление заменяет предыдущее из того же чата. В браузере уведомления показываются как раньше.

## Обновление

- Миграций нет. Изменения только во фронтенде.
- Переход к чату и замена уведомлений работают в VoiceRoomDesktop 1.3.3. Со старыми версиями приложения уведомления ведут себя как раньше.
