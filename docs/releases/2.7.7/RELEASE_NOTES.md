# VoiceRoom 2.7.7 — один микрофон в списке и гейт без лишнего переключателя

Исправления поверх 2.7.6, обратно совместимые. Миграций нет, схема не меняется, откат сводится к подмене тега образа.

## Что изменилось

### Устройства

- Каждый микрофон и динамик показывается в списке один раз. Chrome на Windows добавляет к реальным устройствам служебные записи «Default» и «Communications», которые указывают на то же устройство, поэтому один микрофон выглядел как три. Теперь они скрыты и в меню звонка, и в настройках звука; системное устройство по-прежнему выбирается пунктом «Системный».

### Гейт

- Убран переключатель «Автоматическая чувствительность» в меню микрофона и в настройках звука. Гейт работает по одному правилу: включён — микрофон открывается, только когда звук громче порога на ползунке; выключен — звук проходит всегда. Сохранённый раньше автоматический режим больше не действует, гейт берёт порог с ползунка.

## Обновление

- Миграций и новых переменных окружения нет.
- Окно «Что нового» остаётся на 2.6.0.
