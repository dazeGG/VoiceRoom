# VoiceRoom 2.7.4 — временные комнаты без лишних запросов

Исправления поверх 2.7.3, обратно совместимые. Миграций нет, схема не меняется, откат сводится к подмене тега образа.

## Что изменилось

- Карточка звонка и диалог переключения комнат показывают название временной комнаты, а не её код.
- Вход во временную комнату больше не пытается сохранить её в список аккаунта: сохранить можно только постоянную, сервер отвечал 400.
- Шапка временной комнаты больше не отмечает её прочитанной: состояние прочтения хранится только для комнат из списка, сервер отвечал 404.
- Закрепы запрашиваются только в комнате, закреплённой за аккаунтом. Раньше их зря запрашивали гости (401) и аккаунт сразу после входа во временную комнату (403).
- Из логов миграций убрана ложная запись «Can't determine timestamp» уровня error. node-pg-migrate писал её для каждой миграции при каждом запуске из-за 14-значных префиксов имён, хотя порядок миграций определял верно.

## Обновление

- Миграций и новых переменных окружения нет.
- Окно «Что нового» остаётся на 2.6.0.
