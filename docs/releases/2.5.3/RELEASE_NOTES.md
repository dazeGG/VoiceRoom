# VoiceRoom 2.5.3 — автозапуск desktop-приложения

Патч-релиз для 2.5.2.

## Добавлено

- В настройках desktop-приложения появилась вкладка «Приложение» с переключателями «Автозапуск» и «Автозапуск свёрнутым». Второй доступен, только когда включён автозапуск. В браузере и в старых сборках desktop-оболочки без поддержки автозапуска вкладка скрыта; если оболочка не смогла применить настройку, показывается уведомление.
- Нужна desktop-оболочка с поддержкой автозапуска (VoiceRoomDesktop#23).

## Обновление

- Миграций нет. Изменения только во фронтенде.
