# VoiceRoom 2.5.7 — уведомления о личных сообщениях и русский текст

Хотфикс для 2.5.6.

## Исправлено

- Системные уведомления о новых личных сообщениях снова приходят. Когда сообщения доставляются через очередь, уведомление о комнате отправлялось, а о личном сообщении нет.
- Звук сообщения больше не играет дважды. Одно сообщение комнаты звучало из превью комнаты и из открытой комнаты сразу, а упоминание ещё и из лобби. Теперь каждое сообщение звучит один раз.
- Тексты системных уведомлений на русском. В заголовке личного сообщения имя отправителя, в заголовке сообщения комнаты — «Отправитель — Комната». Заявки в друзья и скрытый текст уведомления тоже переведены.

## Обновление

- Миграций нет. Изменения в API (доставка уведомлений о личных сообщениях), воркере уведомлений, общем пакете и фронтенде.
- Число непрочитанных на панели задач Windows и сохранение размера окна на мониторе с другим масштабом требуют VoiceRoomDesktop 1.3.2.
