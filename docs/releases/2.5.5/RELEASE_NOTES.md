# VoiceRoom 2.5.5 — стабильность CI для выкатки 2.5.4

Хотфикс для 2.5.4.

## Исправлено

- Тесты desktop-мостов (`desktop-autostart`, `desktop-hotkey-service`) запускали отдельный Vite-сервер со слежением за файлами на каждый тест. На CI это роняло процесс тестов без сообщения об ошибке, из-за чего прогон тега v2.5.4 не дошёл до деплоя. Теперь каждый файл использует один Vite-сервер без слежения за файлами.

## Обновление

- Код приложения не менялся: 2.5.5 выкатывает в прод то же, что вошло в 2.5.4.
- Миграций нет.
