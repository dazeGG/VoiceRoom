# VoiceRoom 2.5.10 — оверлей: аватары, свои игры, видимость молчащих

Хотфикс для 2.5.9.

## Изменено

- Оверлей в игре показывает аватары участников и, по желанию, их имена. Кто говорит, виден полностью, остальные приглушены. Зелёной рамки вокруг говорящего больше нет.
- Вместо переключателей «Кто говорит» и «Кнопки микрофона и звука» в настройках теперь «Имена участников»: если выключить, в игре останутся только аватары.
- Слайдер «Видимость молчащих» (20–100 %, по умолчанию 45 %) задаёт, насколько приглушены те, кто сейчас молчит.

## Добавлено

- Блок «Последнее окно» в настройках оверлея: показывает окно, из которого вы переключились в Voice Room, и позволяет добавить его как игру, если оверлей его не распознал. Добавленные вручную игры можно убрать там же.

## Исправлено

- Слайдер оверлея больше не теряет значение при перетаскивании: сохраняется последнее положение, а не первый шаг.

## Обновление

- Миграций нет. Изменения только во фронтенде.
- Новые пункты рассчитаны на VoiceRoomDesktop 1.4.0 (мосты `getForeground`, `addGame`, `removeGame` и аватары в снимке участников). В старых версиях приложения блок оверлея не показывается, как и в 2.5.9.
