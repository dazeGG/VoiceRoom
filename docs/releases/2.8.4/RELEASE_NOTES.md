# VoiceRoom 2.8.4 — иконка приложения под тему

Патч-релиз для 2.8.3, обратно совместимый. Миграций нет, схема не меняется, откат сводится к подмене тега образа.

## Добавлено

- В десктоп-приложении иконка окна, панели задач, трея и Dock теперь подстраивается под выбранную цветовую тему (Volt, Ice, Coral). Веб сообщает приложению тему при запуске и при каждой смене через `window.voiceRoomDesktopAppIcon.setTheme(id)`.
- В браузере и в приложениях без этой поддержки (десктоп до 1.4.2) ничего не меняется.

## Обновление

- Миграций и новых переменных окружения нет.
- Иконки Ice и Coral приходят с десктоп-приложением 1.4.2; до его установки приложение остаётся с прежней иконкой.
- Окно «Что нового» остаётся на 2.8.0.
