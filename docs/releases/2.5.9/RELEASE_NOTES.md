# VoiceRoom 2.5.9 — оверлей поверх borderless-игр

Хотфикс для 2.5.8.

## Добавлено

- В десктопном приложении, в настройках «Приложение», появился блок «Оверлей в игре»: включение, прозрачность, угол экрана, список говорящих, кнопки микрофона и звука, прохождение кликов в игру и клавиша, которая на время включает клики по оверлею.
- Пока вы в голосе и окно Voice Room не в фокусе, приложение может показать компактную панель поверх оконного и borderless режима. В exclusive fullscreen Windows отдаёт монитор игре — оверлей там не появится. Это прямо написано в настройках.
- Кнопка «Показать оверлей сейчас» на 8 секунд поднимает панель, чтобы проверить положение без игры.

## Обновление

- Миграций нет. Изменения только во фронтенде: настройки и снимок участников для шелла.
- Сама панель рисуется VoiceRoomDesktop с мостом `voiceRoomDesktopOverlay`. Пока этой версии приложения нет, пункт настроек не появляется, поведение 2.5.8 не меняется.
