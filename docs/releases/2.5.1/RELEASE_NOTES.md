# VoiceRoom 2.5.1 — участники комнат

Патч-релиз для 2.5.0.

## Исправлено

- Пользователи, которые добавили постоянную комнату в свой список до 2.5.0, не считались её участниками: их не было в списке участников, они не могли ставить реакции и не предлагались в упоминаниях. Миграция `20260911120000_backfill_room_memberships_from_bookmarks` делает их участниками. Забаненные в комнате пользователи, удалённые и временные комнаты пропускаются, существующие записи (в том числе владельцев) не меняются.
- Добавление комнаты в список сразу делает пользователя участником. Удаление комнаты из списка или выход из комнаты снимает участие и убирает комнату из списка. Владелец остаётся участником своей комнаты.

## Обновление

- Миграция только добавляет строки участия с отметкой `source=bookmark_backfill`; её откат удаляет только эти строки.
