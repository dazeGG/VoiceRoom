# Web to web-vue parity ledger

While `apps/web-vue` (the Vue port) exists, a fix made in `apps/web` also lands in `apps/web-vue`. When the fixed area is not ported yet, the fix is listed here instead, and the task that ports that area applies it and removes the entry. An empty table means every fix in `apps/web` is present in `apps/web-vue` or its area needs nothing.
