# VoiceRoom 2.5.0 physical desktop support matrix

G19 is a release-blocking physical-device gate. Browser emulation and screenshots generated by CI may test the verifier, but they do not satisfy this matrix.

## Required rows

Capture exactly one fresh row for each source-required platform: iOS Safari, Android Chrome, iPadOS Safari, desktop Chrome, desktop Firefox, desktop Safari, and the minimum supported VoiceRoomDesktop build. Mobile rows must observe the accessible desktop-install boundary and zero session, WebSocket, LiveKit, audio, media, push-init, or notification side effects. Desktop rows must observe the normal product root. Test notification permission and service-worker state explicitly, including foreground/background or closed state as applicable.

Each row must include exact OS and browser/application versions, UTC capture time, expected and observed result, zero-side-effect result, focus/name/layout checks, notification state, pseudonymous device and profile identity hashes, an independently stored immutable artifact ID/URI/SHA-256, and a reviewer who is not the implementer. The VoiceRoomDesktop row also requires a pseudonymous install identity hash.

The independent artifact is canonical JSON containing the same `platform`, `os`, `client`, `capturedAt`, `expected`, `observed`, `zeroSideEffects`, `accessibility`, `notification`, and `identity` values as its matrix row plus the reviewer identity. Store it outside the repository in the approved immutable evidence archive, then record its resolvable URI and byte SHA-256 in the row. Do not commit screenshots, device identifiers, credentials, or fabricated evidence.

## Freshness and verification

Evidence is fresh for 14 days, must not predate the tested RC build, and must not be in the future. The verifier requires the exact seven-platform set, exact build SHA/version, a distinct artifact ID, artifact digest, device/profile identity tuple and reviewer for every row, and exact equality between row metadata and resolved artifact content. Reused, missing, stale, future, tampered, self-reviewed, failed, or self-attested-only evidence blocks G19 and the release.

Run the contract verifier with:

```text
node --test scripts/test/g19-physical-matrix.test.mjs
```

The tracked evidence index intentionally remains `PENDING_EXTERNAL_PHYSICAL_CAPTURE` until all seven independently reviewed physical artifacts exist. Unit tests proving fail-closed verifier behavior are not physical evidence and cannot change that status.
